Berikut cara paling mudah dari awal sampai project Anda online di GitHub.

1. Install Git

Download Git:

Git Download

Install seperti biasa → next next selesai.

2. Buat Akun GitHub

Buka:

GitHub

Lalu:

Sign Up
buat akun
3. Buat Repository Baru

Di GitHub:

klik tombol New
Repository name:
misalnya:
mahjong-demo
pilih Public
klik Create repository

Nanti muncul halaman seperti:

https://github.com/NAMAANDA/mahjong-demo.git
4. Buat Folder Project

Misalnya:

mahjong-demo

Isi file:

index.html
style.css
script.js
admin.html
admin.js

Buka folder itu di VSCode.

5. Buka Terminal VSCode

Di VSCode:

Terminal
↓
New Terminal
6. Ketik Perintah Ini Satu-Satu
A. Aktifkan Git
git init

Artinya:
mengubah folder menjadi project git.

B. Masukkan Semua File
git add .

Artinya:
semua file dimasukkan ke daftar upload.

C. Simpan Versi Project
git commit -m "mahjong demo"

Artinya:
membuat snapshot project.

D. Ganti Branch ke Main
git branch -M main
E. Sambungkan ke GitHub

Ganti:

USERNAME

dengan username GitHub Anda.

Contoh:

git remote add origin https://github.com/masterxxii/mahjong-demo.git
F. Upload ke GitHub
git push -u origin main
7. Login GitHub Jika Diminta

Kadang Git meminta login browser.

Tinggal:

login GitHub
authorize

Selesai.

8. Project Sudah Online

Nanti project muncul di:

https://github.com/USERNAME/mahjong-demo
9. Agar Bisa Dibuka Jadi Website

Masuk ke:

Repository
→ Settings
→ Pages

Lalu:

Source = Deploy from branch
Branch = main
Save

Tunggu 1 menit.

Nanti dapat link:

https://USERNAME.github.io/mahjong-demo

Project Anda sekarang jadi website online.
